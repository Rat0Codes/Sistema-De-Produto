# Cadastro e Análise de Produtos

Projeto desenvolvido para praticar conceitos fundamentais de lógica de programação utilizando Python e Portugol.

## Funcionalidades

* **Cadastro de produtos:** armazena nome, preço e categoria.
* **Filtragem por preço:** lista produtos acima ou abaixo de um valor informado.
* **Ordenação:** organiza produtos por preço crescente e decrescente.
* **Categorias únicas:** elimina categorias duplicadas.
* **Estatísticas:** calcula o menor preço, o maior preço e a média dos preços.
* **Relatório final:** apresenta os resultados de forma organizada.

## Tecnologias e conceitos

* **Python:** listas, dicionários, tuplas, conjuntos, laços de repetição, funções nativas e f-strings.
* **Portugol:** vetores de tamanho fixo, laços `para`, Bubble Sort e simulação manual de conjuntos.

## Como executar

**Python**

1. Instale o Python 3.
2. Salve o código em um arquivo chamado `main.py`.
3. Execute no terminal:

```bash
python3 main.py
```

**Portugol**

Abra o código no ambiente compatível com a sintaxe utilizada, como o Visualg, e execute o algoritmo.

## Objetivo

Consolidar os fundamentos da programação por meio da implementação de funcionalidades equivalentes em duas linguagens, compreendendo a lógica dos algoritmos independentemente da sintaxe.
